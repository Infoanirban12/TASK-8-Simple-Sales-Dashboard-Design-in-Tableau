# 📊 Task 8 - Simple Sales Dashboard Design (Data Analyst Internship)

## ✅ Objective
To build an interactive Tableau dashboard that visually represents sales performance by product category, region, and time, using the Superstore dataset.

---

## 📁 Dataset
- **File Used:** `Sample - Superstore.csv`
- Columns used: `Order Date`, `Region`, `Category`, `Sales`, `Profit`

---

## 📊 Dashboard Features (in Tableau)
- **Line Chart:** Sales trends over time (Month-Year)
- **Bar Chart:** Sales by Region
- **Donut Chart:** Sales by Category
- **Filter:** Interactive slicer for Region
- **Color Encoding:** Highlights top-performing regions/categories

- ![sales_dashboard](https://github.com/user-attachments/assets/158636cf-b317-4305-b082-fc1b46e471df)


---

## 📌 Insights
1. **West region** consistently had the highest total sales.
2. **Technology** emerged as the highest revenue-generating category.
3. Sales **peaked during November and December**, suggesting seasonal impact.
4. **Central region** showed steady sales with healthy profits.
